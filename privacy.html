Privacy Policy

onoma2 Personal Google Drive Access

Effective date: November 3, 2026.

1. Operator and personal use

This policy governs the personal Google Drive OAuth application operated by the individual who owns the GitHub account onoma2 (the “Operator”). The application is used exclusively by the Operator for personal file transfers and file management. The Operator is its sole user and sole client. The application is not offered as a public service, does not accept registrations, and is not intended to access other people's Google accounts.

The public xformer pages on this website provide documentation for a separate project. They do not provide Google sign-in or receive the application's Google authorization tokens or Drive files.

2. Google data accessed and purpose

With the Operator's explicit authorization, the application uses the Google Drive API to access the Operator's Drive. Depending on the permissions granted and operations the Operator requests, this may include file and folder names, identifiers, sizes, modification times, checksums, other file metadata, storage-quota information, and file contents needed for transfers or verification. Authorized file-management operations may create, read, update, or delete files and folders.

These permissions are used only to carry out the Operator's requested personal file transfers, backup, verification, and file-management operations. OAuth access and refresh tokens are used to authenticate these operations. The application does not collect Google account passwords.

3. Storage and security

Google Drive stores the uploaded files in the Operator's Google account. Local source files, downloaded files, application configuration, authorization tokens, and any transfer logs are retained on systems controlled by the Operator. Logs, when enabled, may contain file names, paths, metadata, and operational errors. This GitHub Pages website is not an application backend and is not used to store Drive files, OAuth tokens, or transfer logs.

Data is transmitted to Google over encrypted HTTPS connections. The Operator is responsible for restricting access to local files and configuration, protecting the devices used, and keeping authorization credentials private. This policy does not assert that local files or application configuration are encrypted at rest.

4. Disclosure and limited use

Google user data is used only for the personal operations described above. It is not sold, rented, used for advertising or profiling, or used to train artificial-intelligence or machine-learning models. The application does not provide other users or third parties with access to the Operator's Drive data. Transfers to Google occur as necessary to perform the requested Drive operations; any further disclosure is limited to what applicable law requires.

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Google processes information under its own Privacy Policy.

5. Retention, deletion, and revocation

Personal files remain in local storage or Google Drive until the Operator deletes them. Any local transfer logs remain until the Operator deletes them. Authorization tokens are retained in the local application configuration for ongoing access until removed or replaced; their validity is also subject to expiry and revocation by Google.

The Operator may revoke the application's access through Google Account connections and remove its credentials from the local application configuration. Revoking access stops future authorized access but does not delete files already transferred. To remove retained copies, the Operator must delete the relevant local files, logs, and Drive files, including items in the Drive trash where applicable.

6. Website hosting

These static pages do not implement Google authorization, account registration, analytics, or tracking cookies. GitHub Pages hosts the website and may process technical request information, including IP addresses, under the GitHub General Privacy Statement. Visiting this website does not grant access to a visitor's Google Drive.

7. Contact and changes

The Operator can be contacted through the website repository's issue tracker. Do not include credentials, authorization tokens, or private file contents in public issues. Because the Operator is the application's sole user, requests concerning access, correction, or deletion are carried out directly by the Operator using the controls described above.

This policy will be updated if the application's purpose or data-handling practices change. The effective date above identifies the current version. Access by additional users would require a review of this personal-use policy before such access is introduced.
