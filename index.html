onoma2 Personal Google Drive Access

A private application for transferring, backing up, verifying, and managing the owner's personal files between local storage and Google Drive.

The owner of the GitHub account onoma2 is the application's sole user and sole client. Access to Google Drive is authorized by the owner through Google OAuth and used only for the owner's requested file operations. The application is for personal use and is not offered as a public service.

What the application does

The application uploads local files and folders to the owner's Google Drive, downloads selected files, checks transferred files, and manages the owner's stored files and folders when requested. It runs on the owner's own computer; this website is its public information page, not a sign-in or file-upload service.

Why Google Drive access is needed

Google OAuth authorization allows the application to perform those operations in the owner's Drive account. File and folder names and identifiers are used to find transfer destinations; sizes, modification times, and checksums are used to compare and verify files; file contents are transferred only as needed for the requested operations. Creating or updating files and folders requires write access, and deletion occurs only when the owner requests a deletion operation. Access is used for personal file management, not advertising, profiling, or serving other users.
